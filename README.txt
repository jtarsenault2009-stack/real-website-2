# Secret Love Page ❤️

## The easy way to customize it

Open **script.js**.

You can change:
- `password` → the password she has to type
- `unlockedTitle` → the words after she unlocks it
- `unlockedSubtitle` → the smaller text
- `finalTitle` → the big title at the end
- `finalMessage` → your long message
- `photoTime` → how long each picture stays (5000 = 5 seconds)
- `floatingEmojis` → the emojis floating around

The pictures are in the **images** folder.

## GitHub Pages
Put `index.html`, `script.js`, and the `images` folder in the new repo.
Then enable GitHub Pages in the repo's Settings → Pages.
